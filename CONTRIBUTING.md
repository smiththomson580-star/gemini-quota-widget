# Contributing

Use Node.js 22 or newer. Run `npm ci`, `npm test`, and `npm run audit:release` before submitting changes. Include tests for changes to quota interpretation or error handling.

Describe the Gemini application version, operating system, page language and reproduction steps. Explain whether values are used or remaining. Never introduce request-count estimates as a fallback for official quota data, and never bypass authentication, verification, sandboxing or archive-integrity requirements.

Keep local generated archives, credentials, usage snapshots, screenshots with account details, and node_modules out of commits. Assets need a documented source and redistribution permission separate from code licensing.

The maintainer reviews contributions under the project's MIT code license. Artwork remains subject to its own terms.
