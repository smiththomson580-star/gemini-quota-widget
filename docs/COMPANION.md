# 猫猫陪伴站 · 0.7.7

右键猫娘或点击快捷条设置按钮打开设置。单击猫娘查看双额度，快捷条上的纸牌按钮打开摸鬼牌。轻点气泡可切换台词或关闭气泡。台词字号随内容和挂件大小调整，短句放大，长句均衡换行。立绘可拖拽和缩放。番茄钟在计时期间显示额外的倒计时入口。

## 满好感 · 柔情之舞

摸头、投喂或陪玩把好感度攒到 **100** 后，猫猫自动切换成柔情猫娘，用摆手、侧步、轻跳和比心的八张姿态图完成一段 **12 秒**的小舞蹈。舞台仅在奖励期间出现，原日常立绘暂时隐藏，用户自定义图片不会被改写。

舞蹈结束后，好感度回到 **80**，恢复原来的猫娘；重新攒到 100 可再次触发。舞蹈期间暂停投喂等养成操作，避免重复记分；轻点舞蹈立绘仍可查看官方双额度，右键或舞台按钮打开设置。点“收起”或在面板关闭时按 Esc，可以提前结束本次奖励，同样结算到 80。

每次柔情猫娘登场时，头顶会同步出现气泡，大喊“柔情猫娘来啦！”，随本次舞蹈收起。轻点立绘查看额度时，登场气泡让位给双额度气泡；下次变身会再次出现。气泡配色跟随主题，减少动态效果时直接显示。

“互动 → 满好感 · 柔情之舞”单独控制奖励。关闭未开始的奖励会保留已有好感度；重新开启时，已满分的存档可以触发。关闭正在进行的舞蹈或趣味互动会完成当前奖励到 80。启用减少动态效果时改为 2.2 秒的静态比心致谢；跳舞中切换减少动态效果会收起本次奖励。

舞蹈开始前等待动作图加载；加载失败不会消耗满好感，设置里会提示重开舞蹈开关重试。刷新或退出会保留已开始奖励的截止时间，重新打开后到期结算，不会重播或重复扣分。支持 Web Locks 的宿主会协调窗口，避免多个可见窗口同时领取；旧宿主会用存储令牌回读做尽力协调。多账户切换仍不在已验收范围内。

这是根据用户立绘参考重新绘制的换姿动画，细节可能有变化。当前动作是原创猫猫摇摆，并未复刻参考视频的编舞或使用其音乐。见 [素材说明](ARTWORK_DANCE.md)。

## 藏在操作里的小彩蛋

- 两秒内连续轻点猫娘五次，会短暂哈气、轻轻抖一下并出现小生气符号；反馈约 2.4 秒，8 秒内不会反复触发。
- 哈气时成功摸头，猫猫会先借出耳朵、再呼噜和好。投喂也可以消气，沿用原有摸头 / 喂食冷却。
- 猫娘打盹时，轻点会醒来并伸个懒腰，同时显示双额度。
- 拖拽、锁定位置后的拖动尝试、取消触摸、右键和长按设置都不计入连点。键盘 Enter / 空格也可轻点互动，长按自动重复不算连点。
- 没有增加常驻按钮或模块。关闭“开启趣味互动”可停用这些彩蛋；哈气声沿用按压音效开关与音量，减少动态效果时保留文字反馈而不抖动。

默认立绘现在是 1254×1254 的透明高清修复版。原始图仍在源码中，用户自行上传的图片保持不变；它是对小图的修复重建，细节可能与原图略有差异，见 [立绘说明](ARTWORK_HD.md)。

## 互动

| 互动 | 反馈 | 冷却 |
| --- | --- | --- |
| 摸摸头 | 亲密度 +2，爱心与呼噜台词 | 2 秒 |
| 小鱼干 | 亲密度 +5，小鱼粒子和投喂台词 | 30 秒 |
| 逗猫棒 | 亲密度 +3；10 秒内点击移动星星，抓到后继续换位置 | 8 秒 |
| 打盹 / 唤醒 | 呼吸动效、睡眠标记与专属台词 | 无 |

亲密度范围为 0–100，只是本机趣味记录，不会降低或增加 Google 官方额度。猫猫不会因长时间没有互动而掉分。可以关闭趣味互动或隐藏快捷条；Esc 可结束逗猫棒。

### 摸鬼牌

点「纸牌」会在猫猫身边的快捷条上展开牌面。八对牌分别发给双方，一张鬼牌随机加入其中一手，共 17 张。你和猫猫轮流盲抽，同点数自动配对弃掉，最后持鬼牌的一方输。指向牌背或用键盘移到牌背时，老实猫在鬼牌前会露怯，演技猫有时会虚张声势。你抽到鬼牌时，猫猫在原立绘上先憋笑再露齿。猫猫抽到或落败时会先愣住再哭。再次点「纸牌」、查看额度或打开设置都会暂时收起牌面，再点「纸牌」即可继续。

打完一局，无论输赢都加 20 好感度，上限 100。退出牌局不结算。牌桌采用 [Bicycle 的 Old Maid 规则](https://bicyclecards.com/how-to-play/old-maid)的抽牌、配对和判负方式，并缩短了发牌规模。

猫猫当面输牌后的三秒内，从「贴贴」喂小鱼干，会触发嘴硬小剧情。她先说还在生气，再把鱼干当成「证物」吃掉。关闭连续小反应或启用减少动态效果时，会直接显示最后一句。

## 猫爪便签与陪工

「贴贴」收纳摸头、投喂和逗猫棒。「便签」可添加、完成和移除本机便签。提醒可选 30 分钟后、下一个 20:00，或自选未来的本地日期和时间。完成便签时猫猫盖爪印。Gemini 关闭或窗口不可见期间到期的提醒，会在回到 Gemini 后补发，默认在专注计时期间延后便签提醒。

「陪工」与设置中的番茄钟共用计时。开始前可直接填写 5–120 分钟的任意整数，留空使用设置中的常用专注时长。可先写下这一轮的目标，到点后确认完成或继续保留目标。当天的完成便签数、实际计完的专注轮数与时长、确认完成的目标数会出现在「今天收工」小结。便签、目标和记录都留在本机。

待办便签旁的「去陪工」可把文字填进下一轮专注目标。选好时长后点「一起开始」计时。

在「今天收工」小结中，可以保存一条最多 80 字的工位书签。下次打开「陪工」，点书签旁的「带入目标」即可继续。书签会保存在本机，清空文字并保存即可移除。

## 更新挂件

「工具 → 检查并更新挂件」读取 GitHub 最新正式 Release，校验版本、适配协议及文件 SHA-256 后安装。完成后保存草稿并重开 Gemini。下载和校验失败时可重试，旧安装会保留备份。旧版用户须先手动安装一次带更新组件的 0.6.0。

安装后自动适配组件随当前用户登录启动，每三秒检查一次 Gemini 最新安装目录。客户端升级后会重新检查入口结构和完整性要求，备份原版后接入。运行中的目标版本会等到正常退出再处理。未来版本出现结构或接口变化时仍可能需要新适配器，检测状态保存在安装目录的 `gemini-widget-compatibility.json`。

## 台词

内置 31 句，分为猫猫玩梗、软乎贴贴和打工搭子。不同入口共享上一句，尽量避免连续重复；只有一句可用时仍会显示那一句。

例如：

- 小基基...
- 好猫猫...
- ！？极其极其？！
- 猫猫祟祟地路过，偷偷给你盖个爪印。
- 已读，乱喵。收到，继续呼噜。
- 今日最佳工位：你的键盘正中央。
- 首席抓虫官到岗，Bug 先别跑！

这些是为挂件重新编写的短句；常见猫梗句式“能有什么坏心思”可参见 [EYESHENZHEN 的用语介绍](https://www.eyeshenzhen.com/content/2021-11/04/content_24707326.htm)。未复制歌曲或商业音频。

自定义台词每行一句，最多 40 句、每句 80 字，点击“保存台词”生效。尖括号等文本按原样显示，不当作 HTML 执行。可关闭内置台词，仅保留自己写的句子。恢复内置台词会清除本机自定义台词，请先导出偏好备份。

## 外观与声音

- 星糖丁香、奶油蜜桃、夜猫蓝紫三套面板配色；昵称不影响官方账户。
- 透明度只作用于立绘，避免把额度文字一起变淡。
- 锁定位置防止误拖，但单击和右键仍可使用。
- 减少动态效果会关闭呼吸、弹跳与粒子动画；系统的减少动态效果偏好也受支持。
- 本地立绘限 WebP / PNG / JPG、2 MB；导入不向第三方上传。无法显示时恢复原图。
- 猫娘按压音效与互动 / 计时完成提示分别控制。提示音量单独可调；选“静音仅冒泡”保留文字提示。

## 额度

只显示现有桌面采集器取得的官方双额度及重置文字。刷新按钮请求一次同步，但仍遵守主进程的请求间隔与失败退避。约 30 秒尝试同步，90 秒未取得新数据时显示“—”。玩法数值与番茄钟不会作为额度来源。

## 番茄钟与偏好

专注可设 5–120 分钟，休息可设 1–30 分钟。开始后可暂停、继续或结束；完成后由用户决定何时开始下一轮。

计时按绝对截止时间核对，而非依赖后台每秒执行，因此刷新页面或暂时最小化后可恢复。关闭 Gemini 后没有系统级后台闹钟，重开时才核对是否结束。浏览器音频还受宿主的播放策略影响。

导入导出只包含陪伴偏好，不包含账户、官方额度、立绘或旧版连接参数。导入校验格式、大小与参数范围。写入本地存储失败时显示“未保存”，本次互动仍可继续，关闭后无法恢复新状态。

## 键盘

猫娘可聚焦，Enter / 空格查看额度，Shift+F10 打开设置。设置选项卡支持左右方向键、Home、End，Esc 关闭面板。窄窗口内通过面板内容区滚动查看更丰富的设置。
