# Security and privacy reports

Please report issues through the repository's private vulnerability reporting feature when available. If it is not enabled, open an issue containing only a high-level description and request a private contact route. Do not publish credentials or exploit details that expose a real account.

Never attach cookies, tokens, API keys, raw browser profiles, application archives, full logs, or unredacted local quota files. Redact account identifiers and machine paths before sharing diagnostics.

This project uses the existing application's session locally. It does not require a new credential, public debug port, disabled sandbox or relaxed browser security policy. Preserve those boundaries in contributions. Installation modifies a local application archive and may require re-verification after application updates.
