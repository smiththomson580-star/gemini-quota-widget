# Default artwork

On 2026-11-04, the maintainer confirmed authorization to publicly redistribute the separate gentle-catgirl dance atlas and requested its inclusion in v0.5.0. The code's MIT license and the artwork distribution terms are documented separately.

`gentle-dance.webp` is a separate 1254×1254 transparent eight-pose (four columns, two rows) atlas derived with the built-in image generation/editing tool from the maintainer's supplied gentle-catgirl reference on 2026-11-03. It is used only during the affection reward and does not replace ordinary/custom artwork. Its character details are AI-assisted redraws; it is not an original high-resolution source or a frame extraction from a video. The PNG-to-WebP conversion is lossless. Prompt and process: `docs/ARTWORK_DANCE.md`. Like the character artwork below, this atlas is separate from the code's MIT license; no additional third-party artwork rights are granted by the code license.

The current default is `catgirl-hd.webp`, a 1254×1254 transparent restoration made with the built-in image generation/editing tool at the maintainer's request on 2026-11-03. It is derived from the preserved 360×360 `catgirl.webp`, not a recovered original high-resolution master. Fine details may differ from the small source. The conversion from generated PNG to WebP is lossless, with identical decoded alpha.

Both character files have the same separate artwork-use boundary described below; neither is covered by the code's MIT license. See `docs/ARTWORK_HD.md` for the edit prompt and process. Users' separately configured local images are not replaced by this default upgrade.

`catgirl.webp` is the character artwork provided by the project maintainer. The maintainer confirmed on 2026-10-30 that they have authorization to publicly redistribute it and requested its inclusion in this project.
